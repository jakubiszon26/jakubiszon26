## 🔭 What I'm working on

- 🏠 Automating my homelab with **Ansible**, **Terraform** and **k3s**.
- **[API Forge](https://github.com/jakubiszon26/apiforge)** 🦀: a Rust + egui desktop app for REST API regression testing. Each scenario is a plain `.afs` text file you can version in Git, and the app shows the same scenario as a diagram of blocks. Edit either one and the other updates.
- **[claude-flatpak](https://github.com/jakubiszon26/claude-flatpak)** 📦: an unofficial Flatpak of Claude Desktop for any x86_64 distro. It updates automatically and the app itself downloads straight from Anthropic with its checksum verified.
- **[niriblue](https://github.com/jakubiszon26/niriblue)** 🐧: my opinionated Fedora 44 bootc image with KDE Plasma, the CachyOS kernel, a Steam gamescope session and automatic image updates.
## 🗂️ Other things I've made
